#+title: sample org-bibtex file for org-async-init

*** COMMENT
The contents of this file consists of sample entries extracted from
org-ref.bib https://github.com/jkitchin/org-ref with
`org-bibtex-read-file'

Export the entries in this file to a temporary bibtex file with
`org-bibtex'
#+begin_src elisp
(with-temp-buffer
  (insert-file-contents "sample-org-ref-bib.org")
  (org-mode)
  (goto-char (point-min))
  (org-bibtex "/dev/shm/sample-org-ref.bib"))
#+end_src
both `org-bibtex-read' and `org-bibtex' are from ol-bibtex.el shipped
with org mode.
